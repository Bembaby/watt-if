# Watt If

A local household scheduling prototype. A person changes an evening's optional chores, inspects exact checked constraints, resolves conflicts, approves the current revision, and downloads an advisory calendar. Three supported optional chores:dryer,dishwasher,e-bike charger. Fictional October1,2026,18:00–24:00. No Alexa/device connection, real prices or measured savings.

The primary operator is a person coordinating an evening at home. Calm reading, clear decisions and recovery matter more than a dense analytics dashboard. The conversation uses actual local Strands/Qwen when available; the manual planner works independently. Model failure must preserve unresolved work and disable approval of old proposals. An exact start differs from a not-before window. Skipped work is explicitly smaller work.

Existing solver, source provenance, approvals and historical exports are preserved. Media services are production tools, not application dependencies. No public changes until exact package approval.
